Features

  • Two-column layout Content panel on the left, full-height hero image on the right via CSS Grid.
  • Collapsible menu Clicking "Our Menu" toggles the list via a CSS .is-open class.
  • Custom web font Bogart Light loaded from CDN with woff2 + woff fallback.
  • Responsive viewport Meta viewport tag prevents incorrect scaling on mobile browsers.

Setup & Usage

Open directly
Windows:  start index.html
macOS:    open index.html
Linux:    xdg-open index.html
Serve locally
Node.js:  npx serve .
          → http://localhost:3000

Python 3: python -m http.server
          → http://localhost:8000

Known Limitations

  • No responsive breakpoints — two-column layout is not optimised for screens narrower than ~600 px.
  • Hero image URL is pinned to a specific Unsplash crop; the image may change if Unsplash rotates the asset.
  • Font is served by a third-party CDN with no uptime guarantee.
